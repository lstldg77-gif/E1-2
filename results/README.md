# 실행 결과

`python main.py`를 실제로 실행해 모든 메뉴를 한 번씩 사용한 기록입니다. 데이터 파일이 없는 상태에서 시작했습니다.

| 파일 | 내용 |
| --- | --- |
| [run_log.txt](run_log.txt) | 실행 화면 전체 기록 (입력값 포함) |
| [state_result.json](state_result.json) | 실행을 마친 뒤 저장된 데이터 파일 |

## 결과 요약

| 항목 | 결과 |
| --- | --- |
| 시작 퀴즈 수 | 5개 (기본 문제) |
| 추가한 퀴즈 | 1개: "리스트의 길이를 구하는 함수는?" |
| 최종 퀴즈 수 | 6개 |
| 풀이 결과 | 6문제 중 5문제 정답, **83.3점** |
| 최고 점수 | 83.3점 (6문제 중 5문제 정답) |
| 오답 | JSON 파일을 처리할 때 사용하는 표준 모듈은? → 정답: json |

## 화면별 기록

### 1. 메뉴와 퀴즈 목록

```text
저장된 데이터가 없어 기본 퀴즈를 사용합니다.

========== 파이썬 입문 퀴즈 ==========
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 퀴즈 삭제
5. 점수 확인
6. 종료
선택: 3

등록된 퀴즈 목록 (총 5개)
[1] Python에서 화면에 값을 출력하는 함수는?
[2] 여러 값을 순서대로 저장하는 자료형은?
[3] 조건에 따라 코드를 실행하는 키워드는?
[4] 함수를 정의할 때 사용하는 키워드는?
[5] JSON 파일을 처리할 때 사용하는 표준 모듈은?
```

### 2. 퀴즈 추가

```text
선택: 2

새로운 퀴즈를 추가합니다.
문제: 리스트의 길이를 구하는 함수는?
선택지 1: len
선택지 2: size
선택지 3: count
선택지 4: length
정답 번호 (1-4): 1
퀴즈가 추가되고 저장되었습니다.
```

추가 후 목록에 6번 문제가 생겼습니다.

```text
등록된 퀴즈 목록 (총 6개)
...
[6] 리스트의 길이를 구하는 함수는?
```

### 3. 퀴즈 풀기

풀 문제 수를 고르면 무작위 순서로 출제됩니다.

```text
선택: 1
풀 문제 수 (1-6): 6

퀴즈를 시작합니다. (총 6문제, 무작위 순서)

[문제 1] 여러 값을 순서대로 저장하는 자료형은?
1. int
2. bool
3. list
4. float
정답 번호 (1-4): 3
정답입니다!

[문제 2] Python에서 화면에 값을 출력하는 함수는?
정답 번호 (1-4): 1
정답입니다!

[문제 3] JSON 파일을 처리할 때 사용하는 표준 모듈은?
1. random
2. json
3. math
4. time
정답 번호 (1-4): 3
오답입니다. 정답: 2. json

[문제 4] 조건에 따라 코드를 실행하는 키워드는?
정답 번호 (1-4): 2
정답입니다!

[문제 5] 함수를 정의할 때 사용하는 키워드는?
정답 번호 (1-4): 4
정답입니다!

[문제 6] 리스트의 길이를 구하는 함수는?
정답 번호 (1-4): 1
정답입니다!

결과: 6문제 중 5문제 정답 (83.3점)

[오답 노트]
- JSON 파일을 처리할 때 사용하는 표준 모듈은? → 정답: json
새로운 최고 점수입니다!
```

선택지 출력은 문제 1과 3에만 남기고 나머지는 줄였습니다. 전체 화면은 [run_log.txt](run_log.txt)에 있습니다.


## 저장된 데이터

종료 후 [state_result.json](state_result.json)에 추가한 문제를 포함한 퀴즈 6개와 최고 점수가 저장되었습니다. 마지막 부분은 다음과 같습니다.

```json
    {
      "question": "리스트의 길이를 구하는 함수는?",
      "choices": [
        "len",
        "size",
        "count",
        "length"
      ],
      "answer": 1
    }
  ],
  "best_score": {
    "correct": 5,
    "total": 6
  }
}
```

실제 게임은 프로젝트 루트의 `state.json`에 저장합니다. 이 파일은 개인 데이터라 `.gitignore`로 제외했고, 이 폴더의 `state_result.json`은 결과 확인용 사본입니다.
